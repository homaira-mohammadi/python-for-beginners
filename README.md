# 🐍 Python for Beginners

A complete, beginner-friendly **10-lesson Python course**, with slides, explanations, runnable Jupyter notebooks, exercises and solutions.

No experience needed: we start from *"What is programming?"* and finish by building real programs and games.

## 🚀 How to Use This Course

### 👩‍🎓 For students
1. Open a lesson folder and read its `README.md`.
2. Open **`lesson.ipynb`**. The easiest way is the **Open in Colab** button (no installation needed!).
3. Run each code cell with **Shift + Enter**, then change the code and experiment.
4. Do the **`exercises.ipynb`** on your own.
5. Check your answers in **`solutions.ipynb`** *after* you've tried.

New to Python? Start with the 👉 [Setup Guide](resources/setup-guide.md).

### 🧑‍🏫 For teachers
- Each lesson's `README.md` has a **suggested class plan** with timings.
- Present the slides, then live-code from `lesson.ipynb`.
- The notebooks contain *predict-the-output* questions with hidden answers. These work well for class discussion.
- Use the exercises as in-class practice or homework.
