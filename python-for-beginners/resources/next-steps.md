# 🚀 Next Steps After This Course

You've learned the foundations of Python. Here is what to learn next, roughly in this order:

| Topic | What it lets you do | Search for |
|---|---|---|
| Files | Save and load data (e.g. keep your contact book after the program closes) | "python open read write file" |
| Modules & `import` | Split code into files; use Python's built-in tools (`math`, `random`, `datetime`) | "python modules import" |
| List comprehensions | Build lists in one line: `[x * 2 for x in nums]` | "python list comprehension" |
| Classes (OOP) | Create your own types, e.g. a `Student` or `BankAccount` | "python classes for beginners" |
| `turtle` | Draw shapes and art with code | "python turtle graphics" |
| `pygame` | Make 2D games | "pygame tutorial" |
| `pandas` & `matplotlib` | Analyse data and draw charts | "pandas for beginners" |

## 📚 Free places to practise
- **Official Python Tutorial**: [docs.python.org/3/tutorial](https://docs.python.org/3/tutorial/)
- **W3Schools Python**: [w3schools.com/python](https://www.w3schools.com/python/), short examples you can try in the browser
- **Exercism (Python track)**: [exercism.org/tracks/python](https://exercism.org/tracks/python), free exercises with mentor feedback
- **Codewars**: [codewars.com](https://www.codewars.com/), small puzzles ranked by difficulty
- **Python Tutor**: [pythontutor.com](https://pythontutor.com/), shows your code running step by step (great for understanding loops!)

## 💡 Project ideas to keep practising
- 🎲 Dice-rolling simulator
- 📒 Contact book that saves to a file
- ⏰ Countdown timer (look up `time.sleep`)
- 🔐 Password generator (use `random`)
- 🧮 Unit converter (km ↔ miles, kg ↔ lb, °C ↔ °F)
- 📊 Grade analyser that reads scores from a file

Keep coding a little every day. That's the secret! 🐍
