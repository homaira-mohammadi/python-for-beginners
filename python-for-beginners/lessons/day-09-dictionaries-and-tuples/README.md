## 🧠 Key concepts

| Concept | Explanation |
|---|---|
| Dictionary | `{"name": "Ali", "age": 20}` — key → value pairs |
| Safe access | `d.get("key", default)` instead of crashing with `KeyError` |
| Add / change | `d[key] = value` |
| Loop | `for key, value in d.items():` |
| Tuple | `(3, 5)` — like a list but can't be changed |
