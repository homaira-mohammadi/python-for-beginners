## 🧠 Key concepts

| Concept | Explanation |
|---|---|
| Index | `"Python"[0]` → `P`, `[-1]` → `n`. Counting starts at 0. |
| Slice | `text[start:stop:step]` — `"Python"[::-1]` reverses it |
| Immutable | You can't change one character; build a new string instead |
| Methods | `upper()` `lower()` `title()` `strip()` `replace()` `find()` `count()` `split()` |
| f-string formatting | `f"{price:.2f}"` → 2 decimal places, `f"{name:<10}"` → align |
