# Day 7 — Lists

⏱️ **Duration:** 90 minutes  ·  [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/homaira-mohammadi/python-for-beginners/blob/main/lessons/day-07-lists/lesson.ipynb)

Students store many values in one variable, change lists, loop through them, use built-in list functions and build a to-do list app.

## 🎯 Learning objectives

- Create lists and use indexes
- Add, change and remove items
- Loop through lists
- Use `len` `sum` `min` `max` `sorted`
- Build lists from user input

## 🧠 Key concepts

| Concept | Explanation |
|---|---|
| List | `fruits = ["apple", "banana"]` — ordered and changeable |
| Add | `append()` (end), `insert(i, x)` (position) |
| Remove | `remove(x)` (by value), `pop()` (last / by index), `del list[i]` |
| Loop | `for fruit in fruits:` · `enumerate()` for numbering |
| `sorted()` vs `.sort()` | new sorted list vs. sort the list itself |
