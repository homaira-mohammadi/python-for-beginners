Students write their own reusable commands with `def`, parameters and `return`, and organise a program into small functions.

## 🎯 Learning objectives

- Define and call functions
- Use parameters and default values
- Return values (and know the difference from `print`)
- Understand local vs global variables
- Organise a program with functions

## 🧠 Key concepts

| Concept | Explanation |
|---|---|
| `def` | `def greet(name):` defines a function; `greet("Ali")` calls it |
| Parameter / argument | The variable in the definition / the value you pass in |
| `return` | Gives a value back and stops the function |
| `print` vs `return` | `print` shows, `return` gives back. A function without `return` gives `None`. |
| Local variable | Created inside a function and only exists there |
