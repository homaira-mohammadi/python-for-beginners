## 🧠 Key concepts

| Concept | Explanation |
|---|---|
| Programming | Clear, step-by-step instructions for a computer — like the steps a coffee machine follows. |
| `print()` | Shows information on the screen: `print("Hello World")` |
| Strings vs numbers | Text needs quotes (`"Hi"`), numbers don't (`2026`). `print("5+3")` shows `5+3`, `print(5+3)` shows `8`. |
| Calculations | `+ - * /` — division always gives a decimal: `20 / 4` → `5.0` |
| Comments | Notes that start with `#`. Python ignores them. |
| Syntax rules | Python is case-sensitive (`print` ≠ `Print`) and indentation matters. |
