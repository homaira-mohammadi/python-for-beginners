## 🧠 Key concepts

| Concept | Explanation |
|---|---|
| `range(5)` | 0, 1, 2, 3, 4 — the stop number is **not** included |
| `range(1, 11, 2)` | start, stop, step → 1, 3, 5, 7, 9 |
| Accumulator | `total = 0` before the loop, `total += x` inside it |
| Nested loops | The inner loop runs completely for every round of the outer loop |
| `end=" "` | Keeps `print()` on the same line |
