## 🧠 Key concepts

| Concept | Explanation |
|---|---|
| `while` | Repeats the block while the condition is True |
| 3 parts of a loop | start (`count = 1`) → condition (`count <= 5`) → update (`count += 1`) |
| Infinite loop | The condition never becomes False. Stop it with ■ or Ctrl + C. |
| `while True` + `break` | Loop until something happens, e.g. the right password |
| `continue` | Skip the rest of this round |
