# Day 10 — Final Project

⏱️ **Duration:** 120 minutes (+ presentation time)  ·  [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/homaira-mohammadi/python-for-beginners/blob/main/lessons/day-10-final-project/lesson.ipynb)

Students review the whole course, learn `try`/`except`, see how to plan a project, build a Student Grade Manager step by step, and choose their own final project.

## 🎯 Learning objectives

- Handle errors with `try` / `except`
- Plan a project (data → functions → menu)
- Build a complete multi-function program
- Build and present their own project

## 🧠 Key concepts

| Concept | Explanation |
|---|---|
| `try` / `except` | Catch errors like `ValueError` so the program doesn't crash |
| Planning | Understand → plan the data → split into functions → pseudocode → build & test in small steps |
| Menu loop | `while True:` + `input()` + `if/elif` + `break` |
